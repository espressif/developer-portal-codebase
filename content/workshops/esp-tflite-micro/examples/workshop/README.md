# ESP-TFLite-Micro Workshop

Gesture-recognition projects for the ESP-SensairShuttle with ESP32-C5 and BMI270.

1. [Original gesture code](idfweb:project?path=../../01-original-gesture-code&preset=editing): three-class starter firmware and training tools.
2. [Assignment 1](idfweb:project?path=../../02-assignment-1&preset=editing): collected samples for the new gesture.
3. [Assignment 2](idfweb:project?path=../../03-assignment-2&preset=editing): complete datasets and trained Keras model.
4. [Final code](idfweb:project?path=../../04-final-code&preset=editing): embedded four-class model and final firmware.

Use the same ESP-SensairShuttle USB connection when switching between projects.
